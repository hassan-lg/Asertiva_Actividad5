# Tarjeta 3: Negociar una fecha de entrega
Situación:
Tienes varias entregas importantes el mismo día y no podrás cumplir con una de ellas a tiempo. Necesitas comunicarte con el docente o con tu equipo para solicitar una extensión.
Reto:
Debes negociar una nueva fecha explicando tu situación de forma clara, responsable y profesional.
Objetivo:
Practicar la negociación asertiva manteniendo credibilidad y compromiso.
